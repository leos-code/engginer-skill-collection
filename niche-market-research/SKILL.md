# 寻找利基市场（小众市场）

## 目标

帮助用户找到一个感兴趣、能够为受众解决问题、有适度竞争、具有盈利与长期发展潜力，并能通过实际发布和测试验证的利基市场。

## 执行方式

按以下七个步骤开展工作。每一步结束时，对照该步骤的检查清单确认进展。需要用户提供兴趣、经验或实际访谈、网站运营结果时，向用户询问或请用户完成对应动作；可通过网络完成的研究，在具备工具时直接执行。无法取得的数据或尚未开展的测试，标记为未完成，不虚构结果。仅以本次任务提供的信息为基础，不使用用户的历史记忆推断其兴趣。

## 1. 思考你的兴趣和激情所在

先不考虑赚钱，帮助用户自由列举兴趣、爱好、热情和擅长的事情。不要因为某个兴趣看起来普通、幼稚或暂时无法变现而排除它。

如果用户缺乏灵感，使用以下问题引导：

- 在业余时间或职业生活中，最期待做什么、获得什么？
- 喜欢访问哪些博客或网站？
- 订阅了哪些内容或服务？当初为什么订阅？
- 朋友经常就什么话题向你请教？你在哪些方面是专家？
- 参加了哪些俱乐部或兴趣团体？为什么喜欢参与？

将想到的内容全部记录下来，包括看似理所当然、平时容易忽略的技能和兴趣。检查不同兴趣之间是否存在重叠或互补关系，尝试把它们组合为候选利基市场。

例如：将烘焙爱好与对《哈利·波特》的兴趣结合，探索主题儿童派对业务。

优先从真正感兴趣的方向出发，因为与陌生领域相比，用户更可能持续投入时间、精力和注意力。

### 检查清单

- [ ] 用户已充分思考自己的兴趣所在。
- [ ] 已列出让用户有激情、感兴趣的事情。
- [ ] 已检查哪些兴趣能够重叠或互补。

## 2. 为你的受众解决问题

针对上一步得到的候选利基市场，找出其中存在的问题，并判断用户能否为目标受众解决这些问题。将兴趣与实际需求结合。

### 浏览线上社区

阅读 Quora 等论坛的问题、评论和讨论，以及相关网站的评论区、评分区和支持小组。记录常见问题，以及用户可能有办法解决的问题。

### 与目标受众交谈

帮助用户与潜在受众交谈，了解：

- 他们遇到了哪些痛点？
- 什么能够让他们的生活更轻松？
- 他们认为市场上还缺少什么？

### 查看竞争对手

找出候选利基市场的主要参与者，研究他们解决了什么问题、遗漏了什么重要问题。查看其社交媒体上的客户反馈，思考能否提供不同且有用的解决方案。

不要局限于尚未有人解决的问题。现有产品或服务过于昂贵、不够方便，也可能是值得解决的问题。考虑能否降低价格或提高便利性。

例如：原文以 Uber 为例，说明如何通过应用程序改善传统路边打车的价格和便利性问题。

### 检查清单

- [ ] 已确定候选利基市场中用户能够解决的问题。
- [ ] 已思考如何解决发现的问题。
- [ ] 已放弃找不到可解决问题的候选想法。

## 3. 开展竞品分析

对剩余的候选利基市场开展竞争对手研究。

不要将没有竞争者直接视为好事：完全没有竞争可能意味着其他人曾经尝试但发现无利可图。适度竞争是市场具有可行性的一个信号；竞争过于激烈则可能导致难以进入。

### 搜索与分析竞争对手

通过 Google 搜索相关主题，记录找到的竞争对手网站。查看其网站、社交媒体、产品和品牌，并逐项分析：

- 他们在创造什么类型的内容？
- 内容质量如何？用户能否做得更好？
- 他们使用什么语气？
- 目标受众是谁？
- 多久发布一次内容？
- 如何与受众互动？
- 客户在 Yelp 等网站上如何评价他们？

结合这些观察，思考用户可以在哪些地方采取不同做法或做得更好。

### 分析搜索结果中的广告

检查 Google 搜索结果页顶部出现的赞助广告数量。大量付费广告可能意味着较强的付费搜索竞争；相较于广告已经饱和的搜索词，付费搜索结果较少的词可能更容易切入。

### 检查清单

- [ ] 已列出搜索结果靠前的竞争对手网站。
- [ ] 已分析这些竞争对手的网站。
- [ ] 已思考怎样做出差异或做得更好。
- [ ] 已检查 Google 搜索结果页，判断竞争是否过于激烈。

## 4. 做关键词研究

了解人们搜索什么、多少人在搜索、为什么搜索。发现具有搜索需求的关键词，但不要只追求最高搜索量。

### 使用关键词研究工具

从原文推荐的五个工具中选择能够访问的工具开展研究：

| 工具 | 用途 |
| --- | --- |
| [Google Trends](https://trends.google.com/trends/?geo=US) | 分析搜索词在一段时间内的流行程度，识别兴趣上升或下降的趋势。 |
| [Google Ads Keyword Planner](https://ads.google.com/home/tools/keyword-planner/) | 查看建议关键词、平均搜索量和竞争情况。 |
| [Ubersuggest](https://neilpatel.com/ubersuggest) | 发现相关关键词和内容创意；输入竞品域名研究其 SEO 策略；可与关键词规划师配合使用。 |
| [Semrush](https://www.semrush.com/) | 研究竞品使用的关键词、长尾关键词和相关搜索查询。 |
| [Ahrefs Keywords Explorer](https://ahrefs.com/keywords-explorer) | 查找关键词建议，了解关键词的排名难度。 |

原文发表于 2022 年，其中关于工具免费使用、试用期限与价格的说明属于当时的信息，不作为当前价格或可用性承诺。

### 开展关键词研究

1. 从候选利基市场的概括性主题开始，在关键词工具中搜索。
2. 发现更具体的关键词、长尾词、常见问题及此前没有想到的相关话题。
3. 了解目标关键词的搜索量、流行程度和竞争情况（或排名难度）。
4. 思考人们为什么搜索这些词，直到能够理解该利基市场中的搜索需求。
5. 选择目标关键词，在流行程度和竞争激烈程度之间取得平衡。搜索量极大的关键词往往也更难获得排名。

### 检查清单

- [ ] 已试用上述部分关键词研究工具。
- [ ] 已发现希望瞄准的目标关键词。
- [ ] 已检查关键词的流行程度和竞争情况。

## 5. 评估利基市场的机会

结合前面得到的兴趣、受众问题、竞品分析和关键词研究结果，进一步评估该利基市场是否适合启动。按照原文的三个问题开展评估。

### 5.1 它是否有利可图？

如果用户准备建立企业或在线商店，应重点了解盈利可能性；如果只是创建博客，对盈利能力的重视程度可以不同。

- 查看 Amazon、Google、eBay 上的热门产品。
- 查找竞争对手网站上的畅销商品。
- 使用 [Exploding Topics](https://explodingtopics.com/) 等网站发现热门产品。
- 使用 [ClickBank](https://www.clickbank.com/) 等网站了解某些产品的赚钱机会。

根据以上信息评估该利基市场的盈利潜力。

### 5.2 谁是你的目标受众？

明确产品推出后面向的具体受众，了解他们的年龄、性别、生活方式、痛点、预算、爱好和文化等相关特征。

结合目标受众，考虑以下选择：

- 使用什么语言和语气。
- 采用什么营销策略，例如侧重电子邮件还是社交媒体。
- 通过哪些平台宣传品牌。
- 创作什么内容。
- 在网站上使用什么图像。
- 采用什么设计，包括字体等细节。

例如：同样是足球博客，面向年轻女孩与面向某家俱乐部的长期球迷，所创作的内容可能完全不同。

### 5.3 你的利基是否常青？

判断该利基市场是否能够持续存在，而不是一时流行的热潮。

- 回顾受众需要解决的问题，思考什么内容、产品或服务能够让他们不断回来。
- 如果销售实物产品，考虑可消耗、需要重复购买的产品，例如食品、饮料、美容产品、烧烤燃料和清洁用品。
- 使用 Google Trends 观察长期关注程度。稳定或稳步增长的趋势是较好的信号；短时间内急剧上升的热度可能在潮流结束后快速下跌。

### 检查清单

- [ ] 已综合评估利基市场。
- [ ] 已研究利基市场的盈利能力。
- [ ] 已考虑具体目标受众。
- [ ] 已检查该利基市场是否常青。
- [ ] 已决定该利基市场是否适合启动。

## 6. 找到你的独特卖点

回答：为什么受众选择用户的产品、服务或内容，而不是竞争对手？

如果暂时无法确定独特卖点，先思考能够为该利基市场增加什么，再结合用户的激情、才能和专业知识，回顾第三步的竞争对手分析。

重点探索：

- 竞争对手表现不足的地方，例如产品展示不佳、缺少个人风格、设计过时。
- 用户能否做出更好的替代品，提供不同的体验。
- 能否提供独特的经验或知识，例如一对一咨询、协助选择产品，或为在线课程提供电子书、视频通话等补充服务。
- 是否存在用户独特技能能够填补的市场空白。
- 是否能够通过微利基提供额外价值，例如配件或赠品。

原文以 Uber 的新式打车预订、追踪体验和价格作为差异化示例。

### 检查清单

- [ ] 已思考独特卖点是什么。
- [ ] 已参考竞品分析，确定可以改进或脱颖而出的领域。
- [ ] 已决定如何为该利基市场增加额外价值。

## 7. 动手测试你的想法

不要永远停留在规划和准备阶段。协助用户在网上发布想法，并通过实际测试了解市场反应。

### 尝试预售

如果可行，建立网站或网店，接受产品或服务的预订单。观察是否有人愿意为这个想法付费。

### 小规模上线

如果没有获得预订单，也可以从小处开始，将利基产品、服务或内容上线。持续查看网站或商店的分析数据，了解受众参与情况。

### 持续测试和改进

如果受众参与度较低，不要立即认定市场没有需求。网站设计或文案也可能影响参与度。

- 尝试 A/B 测试。
- 调整网站设计元素。
- 修改网站文案。
- 观察修改是否提高受众参与度。
- 可以使用原文推荐的 [Optimizely](https://www.optimizely.com/) 进行网站测试。

在用户实际授权、发布和取得数据后，记录真实测试结果。未上线或尚未获得数据时，不把测试计划当作测试结果。

### 检查清单

- [ ] 如果可能，已建立能够接受预订单的网站。
- [ ] 已上线利基产品、服务或内容。
- [ ] 已监测网站分析数据，衡量是否成功。
- [ ] 已进行测试或更改，以提高受众参与度。

## 完成工作

汇总七个步骤的实际结果及尚未完成的事项。帮助用户确定能够解决受众问题、具备独特卖点、关键词竞争程度适中、与竞品有所区别的利基方向。提醒用户认真规划，但不要因追求完美而迟迟不发布；真正的上线和测试是寻找利基市场的重要环节。
