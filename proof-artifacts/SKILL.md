# 功能验收证据

将每轮证据归档在 `proof-artifacts/<run>/`。提供 Markdown 索引，标明测试环境，并逐条链接到实际证据、预期行为和实际结果。记录失败和未验证项。分享前按项目约定处理敏感信息。

## 验收流程

- [HTTP 接口验收](references/http.md)用于采集完整请求和响应、整理审阅页及核对业务结果。接口回归和模糊测试也使用此流程。
